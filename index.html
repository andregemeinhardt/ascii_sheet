How Alt Codes Work

1. Using Alt Codes on Windows

  1. Ensure Num Lock is ON on your numeric keypad.
  2. Press and HOLD the Alt key on the left side of your keyboard.
  3. Type the numeric digits on the numeric keypad (not top number row).
  4. Release the Alt key: the symbol appears instantly!

2. Why Alt+0177 vs Alt+241?

With Leading 0 (ANSI / CP1252)

Typing a leading zero (e.g. Alt + 0177 for ±, Alt + 0137 for ‰, Alt + 0181 for µ) uses the Windows ANSI character set.

Without Leading 0 (OEM / CP437)

Typing without leading zero (e.g. Alt + 241 for ±, Alt + 3 for ♥, Alt + 1 for ☺) uses original IBM PC / DOS code page 437.

3. 4-Digit Unicode Alt Codes (Word / WordPad / RichEdit)

In modern editors, you can type any decimal number up to 4 digits: e.g. Alt + 8240 produces ‰ (permille), and Alt + 8364 produces € (euro)!

4. How to Use this App on Smartphone

  • Tap any sign to view details and copy it directly to your clipboard.
  • Long-press (hold) any sign to pin it to your Favorites bar at the top!
  • Search digits or names: type 177, 0137, plus minus, or mu to instantly find the character.
